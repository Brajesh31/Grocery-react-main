## 1. Root project license

The repository root contains an MIT License with the notice:

`Copyright (c) 2026 Brajesh Kumar`

The root license is intended for original project material that Brajesh Kumar owns or is otherwise authorized to license. The presence of a root license does not transfer ownership of third-party code or grant rights beyond the applicable upstream licenses.

## 2. Scope and ownership

Before treating every file in this repository as covered by the root MIT license, verify its origin and ownership. Files copied from templates, third-party repositories, generated assets, fonts, icons, images, and dependencies may have separate terms. Where a file or directory contains its own license or copyright notice, preserve and follow that notice.

## 3. Embedded admin template

The nested `Client/react/` application identifies itself as Gradient Able Free React Admin Template and includes its own MIT license file and upstream attribution in its README. Preserve that license and attribution. The root license does not replace the template's existing notice.

## 4. Backend package metadata

The backend package manifest declares ISC metadata. Review the package manifest and source ownership before changing that declaration. The root MIT license should not be interpreted as silently changing the package's declared license.

## 5. Dependency and asset notices

- Preserve all existing third-party copyright and license notices.
- Review dependency licenses before distributing bundled dependencies.
- Verify image, icon, font, and template asset rights.
- Do not remove upstream attribution where the license requires it.
- Do not imply that Brajesh Kumar authored third-party code.
