## 1. Commitment

The Grocery React project aims to provide a welcoming, respectful, and constructive environment for everyone who participates in its development or community, regardless of experience, background, identity, or role.

## 2. Expected behaviour

Participants should communicate courteously, provide actionable technical feedback, respect differing viewpoints, accept responsibility for mistakes, protect privacy, and keep discussions focused on improving the project for its users.

## 3. Unacceptable behaviour

Harassment, discrimination, threats, intimidation, personal attacks, deliberate disruption, doxxing, unwanted sexual attention, publishing private information, and repeated bad-faith conduct are unacceptable. Technical disagreement is welcome; abusive conduct is not.

## 4. Scope

This policy applies to repository issues, pull requests, code reviews, discussions, project communication channels, and events where an individual represents the project.

## 5. Reporting

Report conduct concerns privately to the repository maintainer using the contact method on the maintainer's GitHub profile. Include relevant links and a concise description when safe. Do not disclose private information in public issues.

## 6. Enforcement

Reports will be reviewed as promptly as practical. Proportionate actions may include a warning, removal of harmful content, temporary restriction, or permanent exclusion from project spaces. Retaliation against good-faith reports is unacceptable.
